# 01-Cau-truc-prompt-hieu-qua

Mẫu prompt áp dụng trong dự án Dental Management System:

```text
Bạn là Product Owner và kỹ sư phần mềm cho hệ thống Dental Management System.
Hãy phân tích yêu cầu cho hệ thống quản lý phòng khám nha khoa với các chức năng: đặt lịch hẹn, hồ sơ bệnh nhân, lịch làm việc bác sĩ, thanh toán, hồ sơ điều trị, báo cáo doanh thu.
Yêu cầu đầu ra:
1. Liệt kê các user story.
2. Chỉ rõ các chức năng chính.
3. Mô tả Actor, Use case, input/output.
4. Đưa ra mô hình dữ liệu chính.

Với mỗi module, hãy nêu rõ ràng, ngắn gọn và không mơ hồ.
```
