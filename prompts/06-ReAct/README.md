# 06-ReAct

Mẫu prompt áp dụng trong dự án Dental Management System:

```text
Bạn là trợ lý phát triển hệ thống Dental Management System.
Hãy theo quy trình Reasoning-Action: 
1. Phân tích vấn đề về lập lịch hẹn trung tâm.
2. Liệt kê dữ liệu và đối tượng liên quan.
3. Đề xuất action cần làm trong backend, frontend, database.
4. Kiểm tra xem action đã đáp ứng yêu cầu hay chưa.

Ví dụ vấn đề: bệnh nhân không nhận được email xác nhận hẹn.
```
