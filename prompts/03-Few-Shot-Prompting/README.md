# 03-Few-Shot-Prompting

Mẫu prompt áp dụng trong dự án Dental Management System:

```text
Hãy phân loại phản hồi khách hàng của phòng khám nha khoa theo ba nhãn: POSITIVE, NEGATIVE, REQUEST.
Ví dụ: 
- "Tôi hài lòng vì bác sĩ giải thích rõ ràng" -> POSITIVE
- "Lịch hẹn bị trễ" -> NEGATIVE
- "Tôi muốn đặt lịch tái khám" -> REQUEST

Bây giờ hãy phân loại các câu phản hồi sau cho hệ thống Dental Management System:
1. Tôi muốn đổi giờ hẹn sang ngày mai.
2. Bác sĩ rất thân thiện và chuyên nghiệp.
3. Tôi thấy khu vực chờ khá chật.
```
