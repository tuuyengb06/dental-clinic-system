# 11-Prompt-cho-viet-tai-lieu

Mẫu prompt áp dụng trong dự án Dental Management System:

```text
Hãy viết tài liệu API cho module Appointment của Dental Management System.
Nội dung tài liệu gồm: mô tả module, endpoint POST /appointments, endpoint GET /appointments/{id}, tham số request, tham số response, trạng thái lỗi, ví dụ JSON gửi/nhận, xác thực token, và mô tả quy tắc nghiệp vụ liên quan tới hẹn khám.
```
